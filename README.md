# 🐱 GİZLİ KEDİ AJAN DEDEKTÖRÜ

## Dünyanın En Kritik Yazılımı (Belki)

**Uyarı:** Bu yazılım, insanlığın geleceğini etkileyebilecek kadar önemlidir. Komşunuzun sevimli görünen kedisi aslında bir gizli ajan olabilir. Bu proje, o gerçeği ortaya çıkarmak için tasarlanmıştır.

### Neden Bu Proje?

Yıllardır bilim insanları (yani ben) şunu sormuştur:  
*"Neden kediler o kadar gizemli bakıyor? Neden gece yarısı pencereden dışarıyı izliyorlar? Neden kuyruklarını o kadar anlamlı sallıyorlar?"*

Cevap basit: **Ajan olabilirler.**

Bu yazılım, gelişmiş (ve tamamen uydurma) algoritmalar kullanarak kedinizin / komşunuzun kedisinin ajanlık skorunu hesaplar. Sonuçlar %100 doğru olmayabilir ama en azından eğlencelidir.

### Özellikler

- 📡 Uydu bağlantısı simülasyonu
- 🔍 5 kritik soru ile ajan analizi
- 🧮 Gelişmiş skor hesaplama sistemi (rastgele bonus dahil)
- 🚨 Yüksek risk uyarıları
- 😼 Kuyruk morse kodu tespiti
- 🕰️ 03:17 randevu saati kontrolü

### Kurulum

```bash
git clone https://github.com/Tentivory/gizli-kedi-ajan-dedektoru.git
cd gizli-kedi-ajan-dedektoru
python3 kedi_ajan_dedektoru.py
```

Başka bir şey gerekmez. Python 3 yeterlidir. Ajanlar bile bu kadar basit çalışır.

### Kullanım

Programı çalıştırın, soruları dürüstçe cevaplayın.  
Sonuç size kedinin ajan olup olmadığını (veya olmadığını) söyleyecektir.  
Eğer skor yüksek çıkarsa... daha fazla mama verin. Rüşvet her zaman işe yarar.

### Bilimsel Dayanak

Bu proje, şu anki bilinen en gelişmiş kedi ajan tespit yöntemlerini kullanır:
- Göz teması analizi
- Kuyruk frekansı ölçümü
- Miyav aksanı tanıma
- Gizli mikrofon arama protokolü

(Not: Hiçbiri gerçek bilimsel değildir. Hepsi saçmadır. Ama çalışıyor.)

### Katkıda Bulunma

Pull request açabilirsiniz. Ama dikkat edin: Eğer bir ajan iseniz PR'ınız reddedilecektir.

### Lisans

Bu proje "Ne istersen yap" lisansı altındadır.  
Ajan kediler hariç herkes kullanabilir.
